# TarBitTorrent

Торрент-клиент для Windows: один exe на Go, свое окно (WebView2, без браузера), значок в трее, самообновление.
Движок [anacrolix/torrent](https://github.com/anacrolix/torrent).

## Что умеет

- magnet-ссылки, хеши и файлы .torrent: кнопка «Добавить», перетаскивание в окно, Ctrl+V в любом месте, двойной клик по .torrent и magnet-ссылки из браузера;
- окно добавления: папка, выбор файлов, запуск сразу или на паузе, загрузка по порядку (видео можно смотреть, не дожидаясь конца);
- список раздач с фильтрами, поиском, сортировкой, выбором колонок (правый клик по заголовку) и контекстным меню;
- подробности: общее с картой кусков, файлы с приоритетами, пиры с источником (трекер, DHT, PEX, LSD), трекеры со статусом, график скорости;
- ограничение скорости и режим «черепаха», лимит рейтинга, очередь загрузок, перемещение файлов;
- темная, светлая тема или как в Windows (заголовок окна тоже темнеет);
- замер скорости интернета по кнопке: пинг, загрузка и отдача через серверы Ookla (сервер выбирается по пингу), история замеров; на время замера раздачи притормаживаются;
- трей: открыть, пауза/продолжение всех, «черепаха», выход; крестик сворачивает в трей; уведомление о завершении;
- автозапуск с Windows, ассоциация magnet и .torrent;
- самообновление из релизов GitHub.

## Как находятся сиды и пиры

- все каналы сразу: трекеры, DHT, PEX, поиск в локальной сети (LSD, BEP 14), входящие через UPnP/NAT-PMP, TCP и uTP;
- трекеры опрашивает сама программа: видно состояние каждого (работает, ошибка, сиды и пиры в рое), и можно переобъявиться раньше интервала трекера;
- в открытые раздачи подмешиваются живые публичные трекеры (список обновляется раз в 12 часов) и ретрекер провайдера `retracker.local`;
- таблица узлов DHT и известные пиры каждой раздачи сохраняются между запусками: после перезапуска поиск идет сразу;
- «охотник за пирами»: пока у раздачи меньше 8 пиров или минуту нет данных, она переобъявляется на всех трекерах и в локальной сети (15 с, 30 с, 1, 2, 5 мин) и досыпает свежие трекеры;
- приватные раздачи: без публичных трекеров, без DHT и LSD;
- шифрование соединений (помогает, если провайдер режет торренты) и опция «представляться как qBittorrent» для трекеров, которые пускают только известные клиенты.

## Установка и обновление

Скачать `TarBitTorrent.exe` из [релизов](https://github.com/Trashfallen/TarBitTorrent/releases/latest) и запустить, установка не нужна.
Нужен Microsoft Edge WebView2 Runtime: он есть в Windows 11 и обычно в Windows 10.
Когда выходит новая версия, в окне появляется кнопка «Обновить»: программа скачает ее, заменит себя и перезапустится с теми же раздачами.

Данные программы (настройки, раздачи, журнал): `%APPDATA%\TarBitTorrent`.

## Разработка

Нужен Go (версия в `go.mod`). C-компилятор не нужен: сборка с `CGO_ENABLED=0`.

```bat
build.cmd                 :: dist\TarBitTorrent.exe, значок и версия в ресурсах
go test ./...
```

Для отладки с отдельной папкой данных: `set TARBIT_HOME=C:\temp\tbt` перед запуском.
Без `-X main.appVersion` программа считает себя версией `dev`: автозапуск, ассоциации и самообновление выключены.

## Выпуск версии

1. Поднять версию в файле `VERSION`, закоммитить.
2. `git tag v0.1.1` и `git push origin main v0.1.1`.
3. GitHub Actions проверит, что тег совпадает с `VERSION`, прогонит тесты, соберет exe и создаст релиз с файлом `TarBitTorrent.exe`. Установленные копии увидят его сами.
