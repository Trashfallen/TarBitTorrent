# TarBitTorrent

Торрент-клиент для Windows: один exe, без рекламы и лишнего. Движок libtorrent
(тот же, что в qBittorrent и Deluge), интерфейс в отдельном окне, значок в трее.

## Что умеет

- magnet-ссылки, хеши и файлы .torrent: кнопка «Добавить», перетаскивание в окно, Ctrl+V в любом месте, двойной клик по .torrent и magnet-ссылки из браузера;
- окно добавления: папка, выбор файлов, запуск сразу или на паузе, загрузка по порядку (видео можно смотреть, не дожидаясь конца);
- список раздач с фильтрами, поиском, сортировкой, выбором колонок (правый клик по заголовку) и контекстным меню;
- подробности: общее с картой кусков, файлы с приоритетами, пиры с источником (трекер, DHT, PEX, LSD), трекеры со статусом, график скорости;
- ограничение скорости и режим «черепаха», лимит рейтинга, очередь загрузок;
- темная, светлая тема или как в Windows;
- трей: открыть, пауза/продолжение всех, «черепаха», выход; уведомление о завершении;
- автозапуск с Windows, ассоциация magnet и .torrent;
- самообновление из релизов GitHub.

## Как находятся сиды и пиры

- все каналы сразу: трекеры (все и во всех уровнях), DHT, PEX, поиск в локальной сети (LSD), входящие соединения через UPnP/NAT-PMP, TCP и uTP;
- в открытые раздачи подмешиваются живые публичные трекеры (список обновляется раз в 12 часов) и ретрекер провайдера `retracker.local`; в приватные раздачи ничего не добавляется;
- DHT стартует с шести узлов-маршрутизаторов, таблица узлов и известные пиры каждой раздачи сохраняются между запусками: после перезапуска поиск идет сразу;
- «охотник за пирами»: пока у раздачи меньше 8 пиров или минуту нет данных, она переобъявляется на всех трекерах и в DHT, не дожидаясь интервала трекера (15 с, 30 с, 1, 2, 5 мин), и досыпает свежие трекеры;
- шифрование соединений (помогает, если провайдер режет торренты) и опция «представляться как qBittorrent» для трекеров, которые пускают только известные клиенты.

## Установка и обновление

Скачать `TarBitTorrent.exe` из [релизов](https://github.com/Trashfallen/TarBitTorrent/releases/latest) и запустить. Установка не нужна.
Когда выходит новая версия, в окне появляется кнопка «Обновить»: программа скачает новую версию, заменит себя и перезапустится с теми же раздачами.

Данные программы (настройки, состояние раздач, журнал): `%APPDATA%\TarBitTorrent`.

## Разработка

Нужен Python 3.12 (`py -3.12`): для более новых версий у libtorrent пока нет готовых сборок.

```bat
build.cmd                 :: venv, зависимости, dist\TarBitTorrent.exe
.venv\Scripts\python run.py
.venv\Scripts\python -m unittest discover -s tests
```

Для отладки с отдельной папкой данных: `set TARBIT_HOME=C:\temp\tbt` перед запуском.

## Выпуск версии

1. Поднять версию в `tarbit/version.py`, закоммитить.
2. `git tag v0.1.1` и `git push origin main v0.1.1`.
3. GitHub Actions соберет exe и создаст релиз с файлом `TarBitTorrent.exe`. Установленные копии увидят его сами.

Собрать релиз локально без GitHub Actions: `release.cmd` (exe окажется в `release\vX.Y.Z`).
